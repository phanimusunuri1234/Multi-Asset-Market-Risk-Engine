
# Multi-Asset Market Risk Engine 📊

## Overview

Multi-Asset Market Risk Engine is a Python-based framework for measuring and analyzing market risk across equity, fixed-income, and FX portfolios. It implements Historical, Parametric, and Monte Carlo Value-at-Risk (VaR), Expected Shortfall (ES), stress testing, scenario analysis, and portfolio sensitivity analysis in an integrated risk-analysis workflow.

This project demonstrates the application of quantitative market-risk techniques to a multi-asset portfolio, with emphasis on portfolio-level risk measurement, tail-risk estimation, and analysis under adverse market conditions.

---

## Features

- **Historical VaR** — Non-parametric VaR estimation using historical portfolio return distributions
- **Parametric VaR** — Variance-Covariance approach using portfolio volatility and correlation structure
- **Monte Carlo VaR** — Simulation-based estimation of potential portfolio losses
- **Expected Shortfall (ES)** — Tail-risk measurement beyond the VaR threshold at 95% and 99% confidence levels
- **Multi-Asset Portfolio Analysis** — Risk measurement across equities, fixed income, and FX
- **Stress Testing** — Evaluation of portfolio losses under adverse market shocks
- **Scenario Analysis** — Assessment of portfolio behavior under equity, interest-rate, and FX scenarios
- **Sensitivity Analysis** — Analysis of portfolio exposure to key market-risk factors
- **Portfolio Risk Reporting** — Consolidated VaR, Expected Shortfall, stress-loss, and sensitivity metrics for portfolio-level analysis
